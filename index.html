Tentang Saya

// ringkasan-diri

Saya lulusan D4 Rekayasa Perangkat Lunak dari Politeknik Manufaktur Negeri Bangka Belitung dengan predikat Dengan Pujian (Cumlaude, IPK 3.56). Fokus keahlian utama saya mencakup pengembangan web fullstack menggunakan Laravel dan MySQL, serta aplikasi mobile responsif dengan Flutter.

Selama kuliah dan pengalaman bersama tim di Badan Pusat Statistik (BPS) Kabupaten Bangka, saya terbiasa berkolaborasi di sepanjang siklus proyek: menggali kebutuhan lapangan bersama stakeholder, merancang arsitektur sistem, membangun sistem informasi desa (SID), hingga otomasi pengumpulan data melalui Web Scraping dan visualisasi analitik interaktif di Looker Studio.

Di luar rekayasa kode, saya memiliki keunggulan administratif: mahir mengoperasikan Microsoft Office (Word, Excel rumus lanjutan/laporan keuangan, PowerPoint), serta terampil menyusun materi visual presentasi dan editing video menggunakan Canva & CapCut. Saya siap beradaptasi dan memberikan sinergi terbaik dalam tim kerja.
